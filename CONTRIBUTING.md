# Contributing

## No Contributions Accepted

This project is **not accepting contributions at this time**. Pull requests will be
closed without review.

## Why?

TaskMaster Pro follows an open core model. The core is source-available for study
and personal use, but the project is maintained by a single author. External
contributions introduce review overhead and potential security risks that the
maintainer cannot currently absorb.

## What you CAN do

- Read and study the source code
- Use the software for personal, non-commercial purposes
- Open issues for discussion (bug reports, feature requests)
- Fork is not permitted — see LICENSE

## What you CANNOT do

- Submit pull requests
- Fork this repository
- Redistribute this software
- Use this software commercially
- Create derivative works
